Project Objectives

OlympicsAnalytics was created to demonstrate how modern data science and business intelligence tools can be combined to build a professional analytics platform. The project targets students, researchers, and sports analytics enthusiasts who want to explore Olympic data interactively.

The primary goal is to transform raw historical Olympic data into meaningful insights through cleaning, analysis, and interactive visualisation — published as a fully hosted web application.

  • Collect and clean historical Olympic dataset
  • Perform exploratory data analysis using Python Pandas
  • Build an interactive Tableau dashboard and story
  • Embed Tableau into a professional Flask web application
  • Present data insights on country, sport and gender performance
  • Deploy a production-ready web app on Render
  • Document the entire process professionally
02

Problem Statement

The Olympic Games generate enormous volumes of data spanning athletes, events, countries and years. However, raw Olympic datasets are scattered, inconsistently formatted, and difficult to analyse without specialised tools.

Existing publicly available analyses are often static, limited in scope, or require specialised software to view. There is a need for an accessible, interactive, web-based analytics platform that transforms this data into actionable insights visible to anyone with a browser.

Core Problem

How can we create an interactive, web-accessible platform that transforms 120+ years of raw Olympic data into clear, actionable performance insights for countries, athletes, sports and genders — without requiring any specialised software on the viewer's side?

Dataset Challenges
  • Missing medal values for non-winners
  • Inconsistent country/NOC naming
  • Duplicate athlete records
  • Mixed data types (age, year)
  • Records spanning 28 Olympic Games

Dataset Information

The dataset follows the schema of the widely-used Kaggle "120 Years of Olympic History" dataset (athlete_events.csv) originally compiled by sports-reference.com. It covers every Summer Olympic Games from Athens 1896 to Tokyo 2020.

Data & Visualisation Methodology

Data Preparation

Raw CSV data is processed using the prepare_data.py script located in the data/ directory. The script runs automatically when the Flask app starts if stats.json is not present.

Key decisions: athlete records without a medal value (NaN) are kept to preserve participation data. These represent athletes who competed but did not win a medal — an important distinction for gender and nation participation analysis. 

# Load → Filter → Clean → Compute → Export
df = pd.read_csv('olympics_raw.csv')
df = df[df['Season'] == 'Summer']
df.drop_duplicates(inplace=True)
df['Medal'] = df['Medal'].where(
    df['Medal'].isin({'Gold','Silver','Bronze'}), other=np.nan)
df.to_csv('olympics.csv', index=False)
Visualisation Approach

Two layers of visualisation are used: Tableau for rich, interactive dashboards (embedded via API), and Chart.js for built-in charts that render directly from the Flask API without requiring Tableau to be connected.

  • Map — Medal distribution by country (Tableau)
  • Bar Chart — Top 10 countries, sports (Chart.js + Tableau)
  • Line Chart — Medals over time (Chart.js + Tableau)
  • Stacked Bar — Gender participation (Chart.js + Tableau)
  • Doughnut — Medal type distribution (Chart.js)
